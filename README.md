# AI Craze Series

This repository contains the teaching materials for the 12th iT邦幫忙鐵人賽, a 30-day machine learning challenge.

## Introduction

This tutorial series introduces common machine learning algorithms and applies them to practical cases, such as front-end and back-end integration of AI models and API server deployment skills. Each algorithm includes a programming tutorial, allowing you to understand the concepts and practical implementation skills through hands-on practice. This series is presented in the form of video tutorials, and the content will be compiled into an e-book in the future.

## Who is this series for?

*   Those who understand the Python programming language
*   Those who want to implement AI prediction models
*   Those interested in data analysis and prediction
*   Those who want to understand how AI models are integrated and deployed with the backend

## Series Content Plan

*   Introduction to AI
*   Machine Learning (Introduction to common algorithms)
*   Deep Learning (DNN, CNN)
*   Model backend API setup and deployment
*   Front-end and back-end integration concepts

## Development Environment

This series of tutorials will use the [Google Colab](https://colab.research.google.com/notebooks/) cloud service for Python model training, or you can use [Anaconda](https://www.anaconda.com/products/individual)'s Jupyter Notebook to run it locally. The web front-end will use [Visual Studio Code](https://code.visualstudio.com/), but you can also use your favorite development environment, such as [Sublime](https://www.sublimetext.com/), [Atom](https://atom.io/), or [Vim](http://www.vim.org/).
